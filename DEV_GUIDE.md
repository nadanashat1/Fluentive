- 📊 Available pages list

## 🎯 Quick Start

### **Option 1: Start Everything Together (Best)**
```bash
npm run start-all
```
This will start both servers with a beautiful unified display.

### **Option 2: Start Separately**
```bash
# Terminal 1 - Backend
cd backend
npm run dev

# Terminal 2 - Frontend
npm run dev
```
